# Trilhas de fundo dos Reels

Faixas royalty-free, baixadas manualmente do [Pixabay Music](https://pixabay.com/music/)
(sem API — o Pixabay não oferece endpoint de áudio, só imagem/vídeo).
Licença: [Pixabay Content License](https://pixabay.com/service/license-summary/) —
uso comercial livre, sem necessidade de crédito (dado aqui mesmo assim).

| Arquivo | Faixa original | Artista |
|---|---|---|
| `technology-future-innovation-pulse.mp3` | Technology Future Innovation Pulse | alex-morgan |
| `technology-corporate.mp3` | Technology Corporate | PaulYudin |
| `minimal-technology.mp3` | Minimal Technology | NastelBom |

`render-reels.mjs` sorteia uma faixa e um trecho aleatório (do tamanho do vídeo)
a cada Reels gerado. Pra trocar/adicionar faixas, é só colocar/remover `.mp3`
nesta pasta — sem mudança de código.
