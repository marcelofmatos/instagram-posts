# Template v4 (foto ilustrativa via Pexels) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fundo de foto ilustrativa (Pexels) por lâmina, com scrim escuro; emoji do v3 como fallback quando não há foto.

**Architecture:** O claude emite `query` (keywords) por lâmina; o `gerar-post.sh` baixa 1 foto portrait do Pexels (`PEXELS_API_KEY`) para `out/img-0i.jpg`; o `render.mjs` compõe `{{PHOTO_LAYER}}` (foto+scrim) quando `img-0i.jpg` existe, senão usa o emoji (`{{BG_ICON}}`). O `template-v4.html` é o v3 + a camada de foto. Tudo aditivo e retrocompatível (v1/v2/v3 ignoram `{{PHOTO_LAYER}}`).

**Tech Stack:** Node (render.mjs), Chromium headless, Bash + curl + jq (busca Pexels), ImageMagick.

**Spec:** `docs/superpowers/specs/2026-06-19-template-v4-design.md`

- [ ] **Step 2: Inserir o passo de busca Pexels (entre "validar JSON" e "renderizar")**

Em `scheduler/gerar-post.sh`, localizar o início do passo de render:

```bash
# ===== 5. Renderizar a arte =====
STEP="renderizar arte"
```

e inserir, ANTES dele, o novo bloco:

```bash
# ===== 4.5 Buscar fotos ilustrativas (Pexels) — não-fatal; sem foto => emoji =====
STEP="buscar fotos (pexels)"
rm -f "$OUT"/img-*.jpg
if [ -n "${PEXELS_API_KEY:-}" ]; then
  for i in $(seq 1 "$NSLIDES"); do
    ii="$(printf '%02d' "$i")"
    q="$(jq -r ".[$((i-1))].query // empty" "$OUT/conteudo.json")"
    [ -n "$q" ] || continue
    qenc="$(jq -rn --arg q "$q" '$q|@uri')"
    pexels_search() { curl -fsS -m 20 -H "Authorization: $PEXELS_API_KEY" \
      "https://api.pexels.com/v1/search?orientation=portrait&per_page=1&query=$qenc"; }
    resp="$(retry "pexels $ii" -- pexels_search 2>>"$LOG")" \
      || { log "pexels: busca falhou ($ii); usando emoji"; continue; }
    url="$(printf '%s' "$resp" | jq -r '.photos[0].src.portrait // .photos[0].src.large // empty')"
    [ -n "$url" ] || { log "pexels: sem resultado p/ \"$q\" ($ii); usando emoji"; continue; }
    pexels_dl() { curl -fsSL -m 30 "$url" -o "$OUT/img-$ii.jpg"; }
    retry "pexels dl $ii" -- pexels_dl >>"$LOG" 2>&1 \
      || { rm -f "$OUT/img-$ii.jpg"; log "pexels: download falhou ($ii); usando emoji"; }
  done
  log "fotos: $(find "$OUT" -name 'img-*.jpg' 2>/dev/null | wc -l)/$NSLIDES baixada(s)"
else
  log "PEXELS_API_KEY vazio; pulando fotos (usando emoji)"
fi

```
